# Профиль

Имя: Оксана
Сфера: рілс продюсер та продюсер по запускам
Роль: створює контент-стратегію, зйомку рілс і запускає проєкти для клієнтів

## Контекст

Чем занимается: створює контент для рілс, організовує зйомку, керує запуском проєктів і допомагає клієнтам зростати в соцмережах.
Какие задачи решает: допомагає з контент-стратегією, сценаріями, організацією зйомок, запуском проєктів і пошуком клієнтів.

## Технический уровень

Стек: Instagram, Reels, Telegram, Notion, Canva, Google Docs
Опыт с AI: працює з AI як інструментом для контенту, текстів, структури і підготовки матеріалів

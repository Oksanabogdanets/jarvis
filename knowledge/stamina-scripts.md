# Стаміна — правила роботи зі сценаріями Артема

> Читати щоразу, коли Оксана надсилає надиктований текст Артема (російською) для сценарію Reels.

## Хто такі
- **Стаміна** (@stamina_center) — центр здоров'я спини та суглобів, Київ, 2 філії. Клієнт Оксани на Reels.
- **Артем** — головний лікар, обличчя експертного контенту. Надиктовує сценарії російською, голосом.
- **Ілона** — співзасновниця, колишня пацієнтка. Не говорить про лікування.
- Сценарії живуть у Notion: сторінка «Стаміна — погоджені теми» (таблиця: Тема / Референс / Сценарій / Заклик до дії).

## Схема обробки надиктованого (строго по кроках)

1. **Повний переклад українською.** Зберегти зміст повністю і тон Артема: прямий, без прикрас, від першої особи, його ж слова та звороти. Нічого не додавати від себе.
2. **Прибрати ремарки для Оксани** — все, що Артем каже не в камеру: «моя задача сказать…», «ролик технически снят…», «вот что-то такое можно диктовать», «приблизительно так бы я ответил». Це НЕ сценарій.
3. **Прибрати всі повторювання.** Одна думка = один раз. Перевірити: повторні слова («уже/вже», «організм», «з'явився»), повторні думки в різних формулюваннях, подвоєні перерахування.
4. **Не сушити.** Скорочувати, але лишати живі фрази Артема. Не переписувати своїми словами, не робити «правильний маркетинговий текст».
5. **Показати тільки сценарій.** У лапках, без коментарів, без таймінгів, без титрів, без пояснень, що прибрано. Коментар — лише якщо Оксана спитала.
6. **У Notion писати тільки після її «пиши» / «заміни».** Повторне надсилання диктовки або назва теми — це НЕ команда писати.

## Чого не робити
- Не додавати «найкраще лікується у нас» і подібну самопохвалу, якої немає в диктовці.
- Не вигадувати хуки, CTA, титри, таймінги.
- Не залишати вступні фрази про відео-референс у сценарії.
- Не питати «чи записати в Notion» — чекати команду.

## Довжина
Ролик до 40–50 сек ≈ 90–120 слів. Якщо після прибирання повторів довше — сказати, але не різати зміст самовільно.

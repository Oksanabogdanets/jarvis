## Формат видачі текстів (важливо)

Будь-який текст, призначений для публікації (пост, сценарій відео, підпис), віддавати ГОТОВИМ ДО КОПІЮВАННЯ:
- без HTML-тегів і без markdown у чаті — чистий текст
- без моїх приміток усередині тексту; коментарі й пояснення — тільки ОКРЕМО, після тексту, за роздільником
- один пост = один суцільний блок, який виділяється і вставляється без правок
- якщо постів кілька — великі відступи між ними або окремий файл на кожен
- емодзі та жирне ставити тільки коли Оксана попросила
